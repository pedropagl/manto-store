# Manto Store - Loja de Camisas de Time

Vitrine online fictícia para uma loja especializada em camisas de futebol, criada como projeto de portfólio.

## Link do site

Coloque aqui o link do GitHub Pages.

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Site responsivo
- Cards de produtos
- Filtro por categoria
- Botão de compra pelo WhatsApp
- Menu mobile
- Design esportivo e comercial

## Objetivo

Criar um modelo de site que poderia ser usado por pequenos vendedores de camisas, lojas esportivas ou negócios locais.

## O que aprendi

- Criar vitrine de produtos
- Organizar cards com CSS
- Usar JavaScript para filtros
- Criar uma página comercial focada em vendas
- Publicar projeto no GitHub Pages
